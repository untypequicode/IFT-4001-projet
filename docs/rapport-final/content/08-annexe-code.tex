\section{Annexe : Code}

\subsection{Modèles MiniZinc}

Les codes complets des deux modèles MiniZinc sont disponibles :
\begin{itemize}
    \item \textbf{Modèle 1 (e-v1) :} Le code est disponible dans le dossier \texttt{models/e-v1/src/} avec les fichiers principaux \texttt{main.mzn}, \texttt{generic.mzn}, et les contraintes dans \texttt{constraints/maintenances.mzn} et \texttt{constraints/techniciens.mzn}
    \item \textbf{Modèle 2 (l-v1) :} Le code est disponible dans le fichier \texttt{models/l-v1/model.mzn}
\end{itemize}

\subsection{Exemple de données}

Des exemples de fichiers de données sont fournis dans le dossier \texttt{src/instances/} avec les instances small\_01, small\_02, medium\_01, medium\_02, medium\_03, large\_01, large\_02 et large\_03.
